GUÍA SEGURA FIREWALL (fw-prod-01)
PASO 1: Habilitar Reenvío de Paquetes (Kernel)
Bash
sudo sysctl -w net.ipv4.ip_forward=1
echo "net.ipv4.ip_forward=1" | sudo tee -a /etc/sysctl.conf
PASO 2: Resetear y Declarar Políticas (Sin Bloqueo)
Mantenemos las políticas en ACCEPT mientras configuramos para evitar cortes prematuros.

Bash
sudo iptables -F
sudo iptables -X
sudo iptables -t nat -F
sudo iptables -t nat -X

sudo iptables -P INPUT ACCEPT
sudo iptables -P FORWARD ACCEPT
sudo iptables -P OUTPUT ACCEPT
PASO 3: Tu Salvavidas (Reglas Críticas de Entrada)
El cambio clave: Permitimos SSH (22) y VNC (5900) en cualquier interfaz. No los atamos a eth0.

Bash
# 1. Permitir todo el tráfico de conexiones ya establecidas (No colgará tu sesión actual)
sudo iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 2. Permitir interfaz local (Loopback)
sudo iptables -A INPUT -i lo -j ACCEPT

# 3. Permitir SSH y VNC desde CUALQUIER interfaz (Garantiza acceso total)
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 5900 -j ACCEPT
PASO 4: Reglas de Reenvío (Tráfico entre Servidores)
Bash
# Permitir Web (eth1) -> DB (eth2) en los puertos específicos
sudo iptables -A FORWARD -i eth1 -o eth2 -p tcp --dport 3306 -j ACCEPT
sudo iptables -A FORWARD -i eth1 -o eth2 -p tcp --dport 5432 -j ACCEPT
sudo iptables -A FORWARD -i eth1 -o eth2 -p tcp --dport 3050 -j ACCEPT

# Permitir respuestas de la DB (eth2) -> Web (eth1)
sudo iptables -A FORWARD -i eth2 -o eth1 -m state --state ESTABLISHED,RELATED -j ACCEPT

# Bloquear salidas directas a Internet (eth0) desde las redes internas
sudo iptables -A FORWARD -i eth2 -o eth0 -j DROP
sudo iptables -A FORWARD -i eth1 -o eth0 -j DROP
PASO 5: Cerrar el Candado de Forma Segura
Como el paso 3 ya protege tu SSH activamente en cualquier interfaz, ahora puedes denegar el resto de forma segura.

Bash
sudo iptables -P INPUT DROP
sudo iptables -P FORWARD DROP
PASO 6: Persistencia
Bash
sudo apt update && sudo apt install iptables-persistent -y
sudo netfilter-persistent save
